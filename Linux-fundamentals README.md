# Linux Fundamentals

## Project Overview

This project documents my practical learning of Linux command-line operations as part of my cybersecurity training. These exercises establish foundational skills relevant to system administration, security analysis, and ethical penetration testing.

## Learning Objectives

- Navigate the Linux filesystem.
- Identify the current user and system information.
- Create and manage files and directories.
- Understand basic Linux file permissions.
- Practise essential terminal commands.

## Commands Practised

| Command | Purpose |
|---|---|
| `pwd` | Display the current working directory |
| `ls -la` | List files, including hidden files, with details |
| `whoami` | Display the current username |
| `uname -a` | Display system information |
| `cd` | Change directories |
| `mkdir` | Create directories |
| `touch` | Create an empty file |
| `cat` | Display file contents |
| `chmod` | Modify file permissions |

## Practical Exercises

I will record the commands I execute, their outputs, what I learn, and any errors I encounter as I complete each exercise.

## Security Relevance

Linux command-line proficiency is important for inspecting systems, managing permissions, navigating security tools, and conducting authorised security assessments.
